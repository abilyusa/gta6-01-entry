Solmar — a GTA-style open-world crime game. Dario Vega, a broke ex-con in debt to fixer Rosa Marín, runs 5 story missions across a coastal city: steal a sedan, run courier deliveries on a 90-second timer, lose a 3-star police chase, shoot down 4 gunmen at the docks, and rob the Solmar Bank. Explore on foot and by car, steal cars, dodge traffic and pedestrians, build a wanted level with police pursuit, fight with mouse-aim shooting, and save after each job. HUD with minimap, title screen, localStorage saves, synthesised WebAudio sound, pause and mute. Plain static files — no library, no network requests, no assets from any commercial game.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
